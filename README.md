# دیتاست کشف جعل در اسناد فارسی
**Persian Document Forgery Detection Dataset**

یک دیتاست تصویری برای آموزش و ارزیابی مدل‌های **تشخیص و محل‌یابی جعل** در اسناد فارسی (فاکتور، نامه اداری، حکم، فرم بیمه، نسخه، رسید بانکی و ...). هر تصویر دست‌کاری‌شده همراه با **ماسک باینری دقیق در سطح پیکسل** ارائه شده است.

## انواع جعل

| نوع | توضیح |
|---|---|
| `digit_mod` | دست‌کاری ارقام و متن (مبلغ، تاریخ، کد رهگیری، کلمات کلیدی) |
| `copy_move` | کپی و انتقال مهر، امضا یا عدد/واژه در همان سند |
| `splicing` | الصاق مهر، امضا یا پاراگراف از سندی دیگر |
| `inpainting` | پاک‌کردن و پرکردن ناحیه (مثلاً تاریخ یا مهر) |

حدود ۸۰٪ نمونه‌های جعلی تک‌حمله‌ای (single-attack) و حدود ۲۰٪ ترکیبی هستند.

## ساختار پوشه‌ها

```
dataset/
├── train/
│   ├── original/     # تصاویر سالم  (orig_0001.png)
│   ├── tampered/     # تصاویر جعلی  (tamp_0001_01.png)
│   └── masks/        # ماسک متناظر  (tamp_0001_01.png)
├── val/
│   ├── original/
│   ├── tampered/
│   └── masks/
├── test/
│   ├── original/
│   ├── tampered/
│   └── masks/
└── metadata.csv
```

## ماسک‌ها

- فرمت PNG تک‌کاناله (۸ بیتی)، هم‌اندازه با تصویر سند
- `0` = ناحیه سالم، `255` = ناحیه جعل‌شده
- ماسک‌ها همزمان با عملیات جعل و به‌صورت خودکار تولید شده‌اند (نه نقاشی دستی)

## فایل metadata.csv

| ستون | توضیح |
|---|---|
| `id_image` | نام فایل تصویر |
| `Label` | `0` سالم، `1` جعلی |
| `Split` | `train` / `val` / `test` |
| `ref_original` | نام سند پایه‌ای که تصویر از روی آن ساخته شده |
| `file_mask` | نام فایل ماسک (برای اسناد سالم: `None`) |
| `type_manipulation` | `digit_mod` / `copy_move` / `splicing` / `inpainting` |
| `ratio_tamper` | درصد پیکسل‌های جعلی به کل پیکسل‌ها |

## تقسیم‌بندی و عدم نشت داده

تقسیم داده‌ها به نسبت **۷۰٪ آموزش / ۱۵٪ اعتبارسنجی / ۱۵٪ آزمون** و **پیش از اعمال جعل** انجام شده است. هر سند پایه و تمام مشتقات جعلی آن فقط در یک split قرار دارند، بنابراین نشت داده (data leakage) بین train و test وجود ندارد.
